# Память Победы — Исторический портал Ошмянского района

> Веб-проект, посвящённый трагическим событиям Великой Отечественной войны на территории Ошмянского района и подвигу освобождения.

---

## 📖 О проекте

«Память Победы» — это образовательный веб-ресурс, который сохраняет историческую память о:
- Сожжённых деревнях Ошмянского района
- Трагедии Ошмянского гетто и геноциде мирного населения
- Героях-освободителях и боевых операциях
- Памятниках и мемориальных комплексах
- Уроках истории для будущих поколений

Проект создан в рамках патриотического воспитания молодёжи и приурочен к 80-летию Великой Победы.

## 🚀 Быстрый старт

### Клонирование и установка
```bash
git clone https://github.com/ilanmace-crypto/patriot.by.git
cd patriot.by
```

### Локальный запуск
Проект полностью статический — достаточно открыть `index.html` в браузере или использовать любой локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен http-server)
npx http-server

# Или Live Server в VS Code
```

Откройте `http://localhost:8000` в браузере.

## 📝 Локализация

Проект поддерживает два языка. Добавление нового языка:

1. Откройте `assets/js/localization.js`
2. Добавьте переводы в `COMMON_TRANSLATIONS` и `LOCALIZATION_DICTIONARY`
3. Обновите переключатель языков в HTML

```javascript
// Пример добавления нового языка
const COMMON_TRANSLATIONS = {
    ru: { 'nav.home': 'Главная' },
    be: { 'nav.home': 'Галоўная' },
    pl: { 'nav.home': 'Strona główna' }  // Новый язык
};
```

## 🎨 Кастомизация

### Изменение цветовой схемы
Отредактируйте CSS-переменные в `styles.css`:

```css
:root {
    --primary-red: #8B0000;
    --primary-green: #006400;
    /* ... другие переменные */
}
```

### Добавление новых страниц
1. Создайте HTML-файл в папке `pages/`
2. Добавьте переводы в `localization.js`
3. Обновите навигацию во всех файлах
4. Создайте отдельный CSS-файл при необходимости

## 🚀 Оптимизация

### Изображения
- Используйте формат **WebP** для современных браузеров
- Добавьте `loading="lazy"` для ленивой загрузки
- Оптимизируйте размер с помощью инструментов сжатия

### Производительность
- Включен `decoding="async"` для изображений
- Используются `preconnect` для внешних ресурсов
- Минимизированы repaints и reflows
